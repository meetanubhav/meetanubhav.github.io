## About this repository

Source for my personal portfolio at **[meetanubhav.github.io](https://meetanubhav.github.io)**, served by GitHub Pages from the `master` branch.

It is a single, dependency-free page: HTML, CSS and a few lines of vanilla JavaScript, with no build step or framework.

## Highlights

- **Minimal, fast.** One HTML file, no CSS or JS libraries. Only external request is Google Fonts.
- **Light and dark themes.** Follows the system setting, with a manual toggle that is remembered.
- **Responsive.** Designed for phone, tablet and desktop.
- **Accessible motion.** Subtle scroll-reveal animations that switch off under `prefers-reduced-motion`.
- **Share-ready.** Open Graph tags for clean link previews on LinkedIn and Slack.

## Run locally

```bash
git clone https://github.com/meetanubhav/meetanubhav.github.io.git
cd meetanubhav.github.io
python3 -m http.server 8000   # then open http://localhost:8000
```

Or just open `index.html` in a browser.
